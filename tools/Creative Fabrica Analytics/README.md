# 📊 Creative Fabrica Affiliate Analytics & Automation

Кроссплатформенный (macOS & Windows) инструмент для сбора статистики партнёрского кабинета Creative Fabrica:
- **Referrals:** `https://www.creativefabrica.com/affiliate-area/?tab=referrals`
- **Visits:** `https://www.creativefabrica.com/affiliate-area/?tab=visits`
- **Overview:** `https://www.creativefabrica.com/affiliate-area/`

---

## 🔘 ОДНА КНОПКА ЗАПУСКА (ИНТЕРАКТИВНОЕ МЕНЮ)

Для максимального удобства создан мастер-скрипт с наглядным интерактивным меню на русском языке:

- **На macOS:**
  - Просто дважды кликните по файлу **`START_CF_ANALYTICS.command`** прямо в Finder (он откроет Терминал сам)
  - Либо запустите в консоли: `./START_CF_ANALYTICS.sh`
- **На Windows:**
  - Дважды кликните **`START_CF_ANALYTICS.bat`**

### Что есть в меню:
```text
  [1] ⚡ БЫСТРОЕ ОБНОВЛЕНИЕ (Скачать только новые данные за сегодня/вчера)
      ↳ Сканирует страницы вперед (до 100 стр) и останавливается сам,
        когда дойдет до уже сохраненных записей.

  [2] 🔍 ПРИНУДИТЕЛЬНАЯ ПРОВЕРКА N СТРАНИЦ (Выбрать: 10, 20, 50, 100 страниц)
      ↳ Принудительно сканирует выбранное число страниц со стр. 1 без ранней
        остановки, сверяет каждую строку с базой и дописывает/обновляет данные.

  [3] 🔄 ГЛУБОКАЯ РЕВИЗИЯ ВСЕЙ ИСТОРИИ (Перепроверить всё со стр. 1 до конца)
      ↳ Полный проход по всем страницам: находит упущенные записи,
        обновляет конверсии ($0.00 ➔ $9.40) и дописывает их в базу.

  [4] 📈 АНАЛИЗ И АУДИТ ПОТЕРЬ (Мгновенно без браузера)
      ↳ Сверка синих галочек в Visits с Referrals, расчет $0.00 -> $9.40,
        генерация текста тикета в поддержку (missing-referrals-ticket.txt).

  [5] 🚀 ОБНОВИТЬ + ОТПРАВИТЬ В GITHUB (Sync)
  [6] 🔑 АВТОРИЗАЦИЯ В АККАУНТЕ (Login)
  [7] 🛡️ ПРОВЕРКА АНТИДЕТЕКТА (Stealth Verify)
  [0] ❌ ВЫХОД
```

## ⚡ Как работает инкрементальный режим (`npm run update`)

1. **Без искусственных лимитов:**
   - Если за сутки набежало 10, 20 или 50 страниц визитов — скрипт пройдет их все (лимит поднят до 100 страниц).
2. **Прозрачная сверка с базой в реальном времени:**
   - На каждой странице скрипт выводит детальный отчет:
     `Стр. X: Новых: N | Обновлено: M | Уже в базе: K`
3. **Автоматическая остановка:**
   - Для **Referrals**: останавливается, когда на странице все строки уже известны и суммы/статусы не менялись.
   - Для **Visits**: останавливается, когда на странице 0 новых визитов (достигнута граница прошлого сбора).
4. **Связка $0.00 ➔ $9.40:**
   - Если старый лид, который раньше был `$0.00`, оплатил годовую подписку и стал `$9.40`, запись автоматически обновится в базе.

## 📁 Файлы отчетов

- `data/reports/master-database.json` — единая накопленная база всей истории без дубликатов.
- `data/reports/analytics-daily.json` — посуточная сводка по дням (`YYYY-MM-DD`) для веб-интерфейса `index.html`.
- `data/reports/missing-referrals-ticket.txt` — готовый текст обращения в поддержку по потерянным конверсиям с синей галочкой.
