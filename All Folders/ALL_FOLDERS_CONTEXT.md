# 🏗 Контекст папки: All Folders (Шаблоны для отдела автоматизации)

Эта папка — "скелет" и база для внешнего отдела, который занимается массовой регистрацией аккаунтов Pinterest и автоматическим постингом через Make.

## 📁 Суть и Структура
Здесь лежат готовые шаблоны папок под каждую утвержденную нишу (например, `Artify Studio`, `Antistress`, `Weight Loss` и т.д.).
Самая глубокая и важная папка в каждой нише — это **`Template`**. Именно её копирует отдел автоматизации для запуска новой сетки аккаунтов.

## ⚙️ Что хранится внутри `Template`?
*   **`For Main/`**: Содержит два критических файла:
    *   `Boards_Name.txt` — Название главной доски для аккаунта.
    *   `Boards_Tags.txt` — Список отборных тегов. **Отдел использует эти теги, чтобы соскрапить из Pinterest до 3000 релевантных пинов (картинок).**
*   **`!Generators/` (Ссылки):** Файлы `Description Generator` и `Name Accounts` ссылаются на Python-скрипты, генерирующие уникальные имена профилей и био (чтобы аккаунты не банило за спам).
*   **`Cookies/`**: Файлы сессий (использованные, неиспользованные, просроченные) для безопасной регистрации.
*   **`Count Automations` & Токены:** Данные для контроля количества зарегистрированных аккаунтов и токены для загрузки тяжелых CSV-файлов через Make.

## 🔄 Рабочий процесс постинга
1. Отдел берет теги из `Boards_Tags.txt` и парсит чужие картинки.
2. Собирает из них огромный Excel/CSV шаблон.
3. Этот CSV заполняется нашими уникальными ИТ-сгенерированными названиями, описаниями и призывами к действию (CTA), которые ведут на наш сайт-прокладку.
4. Make автоматически выкладывает по **3 пина каждые 3 часа** на созданную доску, постепенно прогружая аккаунт.
