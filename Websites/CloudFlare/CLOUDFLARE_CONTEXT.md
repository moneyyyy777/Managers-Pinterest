# 🌐 Архитектура Cloudflare & Google Sites (Трафиковая прокладка)

Этот документ описывает устройство инфраструктуры, которая отвечает за безопасное перенаправление трафика из Pinterest на наши партнерские ресурсы (Creative Fabrica) через систему многоуровневых "прокладок" (PBN).

## 🔗 Трафиковая Цепочка (Как идет пользователь)
Чтобы Pinterest не банил наши аккаунты за прямые партнерские ссылки, мы используем сложную, но надежную воронку:
1. **Pinterest Пин** (человек кликает по ссылке).
2. **Google Site (Прокладка)** — Трастовый домен от Google. Пользователь видит страницу, внутри которой через Iframe (растянутый на 1800px) встроен наш сайт.
3. **Cloudflare Pages HTML (Защита)** — Тот самый Iframe. Это простая HTML-страница с фейковой капчей ("I'm not a robot").
4. **Artify Studio (Главный сайт)** — После клика по капче пользователь попадает на красивую витрину-подборку на нашем сайте `artify-studio.pages.dev`.
5. **Creative Fabrica** — Пользователь кликает "Free for Download" и уходит по партнерской ссылке приносить нам прибыль.

## 📁 Структура директории `Cloudflare/`

### 1. `artify-studio/` (Главный сайт-витрина)
Это основной сайт на фреймворке **Astro**.
База данных подборок хранится по пути: `content/[Имя раздела]/[Имя подборки]`.
Внутри каждой подборки лежат:
* `Products/` — JSON-файлы каждого товара (картинки, названия, ссылки).
* `all_products.json` — Сводный файл всех товаров подборки.
* `collection.json` — Порядок отображения товаров.
* `info.json` — Заголовок, описание и обложка страницы.
* `links.txt` — Сырые ссылки на товары.

### 2. `!Creative Fabrica HTMLs/`
Здесь хранятся те самые HTML-файлы с "капчей".
Они выгружаются на Cloudflare Pages под уникальными сабдоменами (например, `fontsluxury-artifystudio.pages.dev`). Именно эту ссылку мы вставляем в Google Site.

### 3. Базы данных и учет
* **`analytics_g_rules.json`** — База данных кодов Google Analytics (GA4). Мы автоматически создаем новый ресурс Аналитики под каждую подборку, чтобы отслеживать трафик. Формат: `{"brand": "Cloudflare", "suffix": "WL", "thematic": "Fonts Luxury", "code": "G-V974VQDD0W"}`.
* **`Cloudflare accounts.txt`** — Огромная записная книжка. Т.к. на одном бесплатном аккаунте Cloudflare можно держать только 500 сайтов (мы делаем по 150 для запаса правок), здесь мы ведем строгий учет: какой email владеет какими подборками, и храним все 4 ссылки (CF Page, Artify Studio, Google Site Public, Google Site Edit).

## 🔄 Связь с `ALL FOLDERS` (Финальный этап)
Когда цепочка (Cloudflare Page + Google Site + Analytics) создана, ссылка на редактирование этого Google Site (`Link_Site.txt`) автоматически вшивается внутрь папок `1...`, `2...` с тегами из творческой мастерской. 
Затем эти папки упаковываются в раздел `ALL FOLDERS`, чтобы отдел регистрации и автоматизации (Make) просто взял папку, загрузил в систему и начал массовый постинг 3000 пинов, которые поведут трафик ровно на эту настроенную цепь.
