# Комплексный аудит проекта Artify Studio (Astro + Tailwind)

Этот файл подготовлен для ИИ (Claude / ChatGPT / Gemini) как контекстный мост. Он описывает текущую архитектуру, логику и "узкие места" проекта, чтобы ИИ мог продолжить работу над сайтом без потери контекста.

## 1. Архитектура и Стек
* **Фреймворк:** Astro (Static Site Generation - SSG).
* **Стили:** Tailwind CSS.
* **Хостинг:** Cloudflare Pages.
* **БД / Контент:** JSON файлы, лежащие в локальной директории `content/[category]/[collection]`.
* **Цель сайта:** Агрегатор творческих ассетов (шрифты, кисти Procreate, SVG) для генерации премиального Affiliate-трафика (преимущественно из Pinterest) на платформу Creative Fabrica.

## 2. Структура Директорий
* `src/pages/index.astro` — Главная страница сайта.
* `src/pages/[category]/index.astro` — Страница категории (например, `/fonts/`), отображающая сетку подборок (Collection Cards).
* `src/pages/[category]/[collection].astro` — Страница конкретной подборки (например, `/fonts/bubble-fonts/`), отображающая сетку товаров (Product Cards).
* `src/layouts/BaseLayout.astro` — Главный каркас всего сайта. Содержит метатеги (SEO) и скрипты аналитики (GA4, Clarity).
* `src/layouts/Layout.astro` — Резервный/устаревший layout, сейчас почти не используется.
* `src/components/` — Карточки `ProductCard.astro`, `CollectionCard.astro`, навигация `Header.astro`, `Footer.astro`.
* `src/utils/build-affiliate-url.js` — Функция-билдер для генерации партнерских ссылок с привязкой параметров `?campaign=artifystudio-[category]-[campaign]` и ID партнера (`ref/8122976/`).

## 3. SEO и Метатеги (Что нужно улучшить)
На данный момент `BaseLayout.astro` принимает только базовые пропсы `title` и `description`.
**Что должен сделать ИИ для улучшения SEO:**
1. Добавить поддержку тегов **Open Graph (`og:title`, `og:description`, `og:image`)** и **Twitter Cards** в `BaseLayout.astro`. Это критически важно для красивых сниппетов при шеринге в Pinterest, Facebook, iMessage.
2. Сделать так, чтобы страницы категорий и коллекций прокидывали динамическую картинку (`og:image`) обложки подборки в `BaseLayout`.
3. Добавить `<link rel="canonical" href="..." />`, чтобы избежать санкций Google за дублированный контент (если страницы будут дублироваться с UTM-метками).
4. Добавить микроразметку Schema.org (JSON-LD) формата `Product` или `ItemList` на страницы коллекций.

## 4. UI / UX Карточек (Что нужно улучшить)
Мы уже реализовали кликабельность фотографий в карусели `ProductCard.astro`, а также добавили кнопки (стрелочки) для ПК и бесконечное зацикливание при перелистывании.
**Что должен сделать ИИ для улучшения UI:**
1. **ProductCard.astro**:
   * Сейчас картинки растягиваются через `object-cover`. Для некоторых шрифтов или кистей может обрезаться важный текст. ИИ должен продумать, стоит ли менять на `object-contain` или комбинировать с фоном.
   * Добавить микро-анимацию кнопки "FREE FOR DOWNLOAD" (например, легкую пульсацию `animate-pulse` или эффект `hover:scale-105`), чтобы повысить CTR.
2. **Навигация**:
   * На страницах подборок стоит внедрить **Хлебные крошки (Breadcrumbs)**: `Home > Fonts > Bubble Fonts`, чтобы улучшить внутреннюю перелинковку (внутренний вес страниц) и навигацию для пользователя.

## 5. Производительность и Контент (Что нужно улучшить)
* **Аналитика:** Идеально настроена (сырые скрипты без песочниц, работает Edge Analytics на Cloudflare).
* **Изображения:** В карточках используются `img` с `src`. 
  **Важная задача для ИИ:** Astro имеет встроенный мощный компонент `<Image />` из `astro:assets`. Он автоматически сжимает картинки в формат `webp`/`avif` и генерирует `srcset`. Сейчас картинки грузятся "как есть", что может убивать Core Web Vitals (LCP) на тяжелых страницах с 50+ товарами. ИИ должен перевести карточки на использование `<Picture />` или `<Image />`, либо добавить CDN-параметры сжатия, если URL картинок внешние.

## 6. Как ИИ (Claude) должен работать дальше:
* Не предлагайте использовать React/Vue/Svelte без крайней необходимости. Сайт должен оставаться 100% статичным (Zero-JS) за исключением микро-скриптов UI (вроде карусели), чтобы выдавать 100/100 баллов в Google PageSpeed.
* Внимательно читайте JSON-структуру перед парсингом.
* Сохраняйте Tailwind-подход к верстке (никакого внешнего CSS, кроме `global.css`).
