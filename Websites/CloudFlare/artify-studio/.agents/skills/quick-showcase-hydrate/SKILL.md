# ⚡ Скилл: Быстрый сбор витрины (Черновики) и Допарсинг одобренных товаров

Этот скилл решает проблему долгого ожидания при сборе больших подборок (300-800 товаров).
Вместо ожидания часами, система работает в 3 быстрых этапа:

1. **⚡ Быстрый сбор витрины (1-2 минуты):** Собирает фото, названия и ссылки прямо со страниц поисковой выдачи Creative Fabrica. Создаёт карточки со статусом `⚡ Черновик`. Вся витрина сразу отображается в админке `http://localhost:3333`!
2. **🧹 Модерация менеджером:** Менеджер открывает админку, удаляет неподходящие товары в корзину и оставляет только нужные клипарты.
3. **🎯 Финальный допарсинг:** ИИ докачивает полные HD-галереи, подробные описания и отзывы только для тех товаров, которые одобрил менеджер!

---

## 🛠️ Доступные команды скрипта

### 1. Проверить статус черновиков в подборке
```bash
node .agents/skills/quick-showcase-hydrate/scripts/manage-showcase.js status <категория> <подборка>
```
*Выведет общее число товаров, сколько из них черновиков и сколько чистовых.*

### 2. Сделать быстрый сбор витрины (по for_links.txt)
```bash
node .agents/skills/quick-showcase-hydrate/scripts/manage-showcase.js quick <категория> <подборка> [лимит]
```
*Берёт ссылки из `content/<категория>/<подборка>/for_links.txt`, за 1-2 минуты собирает карточки и создаёт витрину в админке.*

### 3. Допарсить одобренные менеджером черновики
```bash
node .agents/skills/quick-showcase-hydrate/scripts/manage-showcase.js hydrate <категория> <подборка> [лимит]
```
*Находит оставшиеся черновики после модерации и скачивает по ним полную информацию (галерею, описание, отзывы), снимая статус черновика.*
