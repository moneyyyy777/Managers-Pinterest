# Artify Studio Design System

## Design Direction

Artify Studio should feel like a premium creative discovery platform.

The feeling:

- modern
- creative
- minimal
- premium
- inspiring

The user should feel like they are exploring a curated design gallery.

---

# Design Principles

## Mobile First

Every component must be designed for:

- mobile
- tablet
- desktop

Mobile experience has highest priority.

---

# Layout

Main container:

- centered content
- large whitespace
- clean hierarchy

Cards:

- rounded corners
- beautiful images
- subtle shadows
- smooth hover animations

---

# Typography

Style:

Premium editorial typography.

Headings:

Large
Bold
Creative

Body:

Clean
Readable
Simple

---

# Color System

Primary:

Dark premium background

Secondary:

Soft neutral colors

Accent:

Creative highlight colors

Avoid excessive colors.

The design should feel expensive.

---

# Components

## Collection Card

Purpose:

Show curated collections.

Contains:

- image
- collection title
- short description
- category label
- product count
- CTA


## Product Card

Purpose:

Recommend individual products.

Contains:

- preview image
- product title
- category
- button


## Category Card

Purpose:

Show main sections:

- Fonts
- Procreate
- SVG


---

# Animation

Use subtle animations.

Examples:

- hover lift
- image zoom
- fade transitions

Avoid excessive animations.

---

# Responsive Rules

Mobile:

1 column cards

Tablet:

2 columns

Desktop:

3-4 columns


---

# Performance

Images must be optimized.

Avoid unnecessary JavaScript.

Use Astro components whenever possible.
