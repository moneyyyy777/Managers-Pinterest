## 1. Архитектура и ключевые компоненты

### 1.1. Браузерное расширение (Artify Studio Clipper)
Расширение работает в любом Chromium-браузере (Chrome, Яндекс Браузер, Brave, Edge) на macOS и Windows без сторонних зависимостей и без необходимости запускать Playwright.

* **Папка расширения:** `extension/`
* **Готовый архив:** `artify-extension.zip`
* **Файлы:**
  - `extension/manifest.json` (Manifest V3)
  - `extension/content/content.js` (инъекция оверлеев, сбор DOM, плавающий бар, обход капчи)
  - `extension/content/content.css` (стили оверлеев, чекбоксов, бейджей популярности)
  - `extension/popup/popup.js` / `popup.html` (интерфейс расширения, выбор категорий/подборок, создание подборок, универсальный допарсинг)
  - `extension/background/background.js` (Service Worker: фоновый скрейпер через реальные скрытые вкладки браузера `scrapeProductPageViaTab`)

#### Ключевые возможности и защитные механизмы расширения:
1. **Режим сбора:** Всегда **`full`** (полный сбор). Режим черновиков упразднён. Любое добавление (по одному, пачкой или со страницы) сохраняет весь товар целиком: заголовок, автора, цену/лицензию, HD-обложку, все слайды галереи, теги дизайнера, лайки, рейтинг и полное описание.
2. **Защита от Cloudflare Turnstile (`isCloudflareChallengePage`):**
   - Автоматически определяет страницы проверки безопасности (`Один момент...`, `Подтвердите, что вы человек`).
   - Блокирует ошибочное добавление пустой страницы капчи в базу.
   - Показывает во вкладке предупреждающий баннер. После клика пользователем по капче и перехода на товар — мгновенно активирует кнопку добавления.
   - Фоновый воркер при обнаружении капчи временно активирует вкладку, чтобы менеджер мог нажать галочку.
3. **Автоматическое закрытие и очистка модальных окон (`dismissAllAccessModal`):**
   - Окно «Try All Access for FREE» (`#payments-dialog`) автоматически закрывается кликом по крестику.
   - Перед извлечением структуры DOM клонированный документ очищается от `#payments-dialog` и любых `[role="dialog"]`, благодаря чему `<h1>` товара никогда не путается с рекламой подписки.
4. **Сбор шрифтов и сложных галерей:**
   - Поддерживает слайдеры `.fotorama`, `.hero-wrapper`, `.product-slider`, `[data-testid="product-gallery"]`.
   - Имена файлов слайдов автора (даже если они не содержат слаг товара) сохраняются в оригинальном разрешении без сжатия (`-580x387` и `-1-1` удаляются регулярными выражениями).
   - Описание шрифтов считывается из `#single-product-description` и `.single-product-description`. Если блок описания отсутствует, создается валидный `<p>${metaDesc}</p>`.
5. **Точный подсчет лайков и рейтинга:**
   - Лайки изолированы строго по `#favorite-count` (не цепляют соседние товары в футере).
   - На карточках каталога/поиска детектируется формат `★ 1 |` и SVG-звезды. Бейдж `⭐ 1` крепится в верхний бар карточки рядом с чекбоксом.
6. **Плавающий менеджер и наблюдатель DOM:**
   - Закреплён в правом нижнем углу с возможностью переключения позиции `top` / `bottom`.
   - `MutationObserver` и циклический watchdog (1500ms) гарантируют, что плавающий бар не исчезает при бесконечной прокрутке (Infinite Scroll) и динамической подгрузке страниц.
   - Независимые корзины для каждой подборки (`collectionsBasket`), история выбора Undo/Redo (`selectionHistory`), сохранение состояния в `chrome.storage.local`.
   - Удобный создатель подборок с автоматической генерацией короткого slug без дублирования названия родительской категории.

### 1.2. Локальный сервер управления (`scripts/admin/server.js`)
* **Порт:** `http://localhost:3333`
* **Запуск:** `npm run admin` (или `ADMIN_CONTROL.bat` на Windows)
* **API эндпоинты расширения:**
  - `GET /api/extension/categories` — список всех категорий и подборок сайта.
  - `GET /api/extension/status` — проверка существующих слагов в подборке, удаленных товаров (корзина) и неполных товаров.
  - `GET /api/extension/incomplete-products` — универсальный эндпоинт поиска товаров, требующих допарсинга (на всем сайте, в категории или в конкретной подборке).
  - `POST /api/extension/add-product` — добавление/обновление одного товара с автоматическим формированием `products/<slug>.json`, `all_products.json`, `collection.json`, `links.txt`, `info.json`. Режим по умолчанию — `full`, `isDraft: false`.
  - `POST /api/extension/add-batch` — пакетное добавление товаров с сохранением очередности и позиции (`top` / `bottom`).
  - `POST /api/extension/create-collection` — создание новой папки подборки со всеми служебными файлами.
* **Функция проверки качества товара (`isProductIncomplete`):**
  Товар считается полным, если у него есть описание длиной от 15 символов (`fullDescription || description`), главное изображение/галерея и снят флаг `isDraft`.

### 1.3. Витрина сайта (Astro SSG + Tailwind CSS)
* **Папка:** корень репозитория `Websites/CloudFlare/artify-studio`
* **Сборка:** `npm run build` (генерирует статичные HTML-страницы в папку `dist/`)
* **Особенности:**
  - Мгновенная загрузка за счет статической генерации (SSG).
  - Оптимизированные изображения с атрибутами `loading="lazy"` / `decoding="async"`, preconnect-хинты для внешних CDN.
  - Умные фильтры категорий и подборок на клиенте без тяжелых JS-библиотек.
  - Полноценные OpenGraph и Twitter Cards метатеги для SEO и соцсетей.

## 2. Неприкосновенные правила для будущих изменений (Инварианты)

1. **Не возвращать черновики:** Все товары должны сразу писаться в полном виде с `isDraft: false`.
2. **Не заменять фоновый сбор на внешний headless браузер:** Фоновый скрейпинг через живые вкладки (`scrapeProductPageViaTab`) обходит блокировки Cloudflare на 100% благодаря реальной сессии браузера менеджера.
3. **Всегда чистить диалоговые окна:** Любые новые селекторы парсинга заголовков должны сначала вычищать `#payments-dialog` и модалки.
4. **Сохранять структуру файлов подборок:**
   Каждая подборка строго содержит:
   - `all_products.json` — общий массив объектов товаров;
   - `collection.json` — упорядоченный список слагов `{"items": [...]}`;
   - `info.json` — название, обложка, описание и счётчик `count`;
   - `links.txt` — список прямых ссылок на товары;
   - `products/<slug>.json` — индивидуальные JSON каждого товара;
   - `delete_links.txt` — удаленные в корзину товары (чтобы они не добавлялись повторно случайно).
5. **Проверять синтаксис и сборку перед коммитом:**
   `node -c` для всех JS файлов, `npm run pack:extension` и `npm run build`.
