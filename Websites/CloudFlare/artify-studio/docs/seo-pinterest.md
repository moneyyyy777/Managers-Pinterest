# Artify Studio SEO & Pinterest Strategy


# Main Goal

The website is optimized for:

1. Pinterest traffic
2. Google organic traffic
3. Creative Fabrica affiliate conversions


The website is not only a catalog.

It is a discovery engine for designers.


---

# SEO Philosophy

Every collection targets a specific search intent.

Examples:


"Nature Procreate Brushes Free"

"Bubble Fonts Free"

"Luxury Fonts For Branding"

"Cricut SVG Designs"


Each keyword should have:

- dedicated collection page
- optimized title
- optimized description
- Pinterest-friendly images
- internal links


---

# Content Strategy


Priority:

Collections > Products


A collection page should rank and collect traffic.

Products support collections.


Example:


Pinterest Pin:

"50 Best Bubble Fonts For Designers"


↓

Website:

/fonts/bubble-fonts


↓

Products:

Creative Fabrica affiliate links


---

# Collection SEO Structure


Every collection page contains:


SEO Title

Meta Description

H1

Introduction

Product recommendations

Related collections

FAQ

Internal links


---

# Pinterest Optimization


Every collection should have:


Vertical images:

1000 x 1500 px


Pinterest-friendly:

- clear title on image
- beautiful preview
- strong keyword


Example:


Image text:

"50 Free Bubble Fonts"


Description:

"Discover the best bubble fonts for logos, Cricut projects and creative designs."


---

# Internal Linking


Every page should recommend:


Related collections

Similar categories

Popular content


Example:


Bubble Fonts

links to:

- Cute Fonts
- Cartoon Fonts
- Kids Fonts
- Handwritten Fonts


---

# URL Structure


Clean URLs:


/fonts/bubble-fonts


/procreate/nature-brushes


/svg/cricut-designs


Avoid:

/product?id=123


---

# Technical SEO


Every page requires:


Title tag

Meta description

Canonical URL

Open Graph

Twitter Card

Schema markup

Sitemap


---

# Performance SEO


Important:

Fast loading

Optimized images

Minimal JavaScript

Static generation

Mobile first

100

collection pages
