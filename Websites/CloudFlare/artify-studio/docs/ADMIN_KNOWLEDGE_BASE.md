# 📚 База знаний проекта и руководство менеджера (Artify Studio)

## 1. Общая архитектура проекта
- **Сайт:** Artify Studio — каталог цифровых товаров (шрифты, клипарты, кисти Procreate, бесшовные паттерны, SVG, планеры и др.).
- **Движок:** Astro (Static Site Generation — SSG), хостинг на Cloudflare Pages.
- **Партнёрские товары:** Creative Fabrica (каждый товар имеет slug, каноническую ссылку, обложку, рейтинг, отзывы, избранное).
- **Контент хранится локально в JSON-файлах:**
  - `src/data/categories.json` — реестр категорий и подборок.
  - `content/<category>/<collection>/all_products.json` — полная база товаров подборки.
  - `content/<category>/<collection>/collection.json` — порядок отображения товаров на сайте.
  - `content/<category>/<collection>/filters.json` — фильтры подборки (id, label, keywords).
  - `content/<category>/<collection>/trash.json` — корзина удалённых/исключённых товаров.
  - `content/<category>/<collection>/delete_links.txt` — чёрный список перманентно удалённых ссылок.

## 2. Локальная панель управления (Админка)
### 🚀 Запуск админки
В терминале проекта выполнить:
```bash
npm run admin
```
Админка откроется по адресу: **http://localhost:3333**

### 🌟 Основные возможности админки:
1. **Витрина товаров:**
   - **Перетаскивание (Drag & Drop):** за верхнюю часть карточки (`⠿ Перетащить`) можно свободно менять товары местами.
   - **Кнопка `↑ 1-й`:** моментально поднимает товар на самое первое место витрины.
   - **Кнопка `№`:** ввод позиции вручную цифрой (например, переместить на 15-е место).
   - **Кнопка `+ Сюда`:** вставка нового товара по ссылке с Creative Fabrica прямо перед выбранной карточкой.
   - **Кнопка `↪️` (Перенос):** перенос товара в любую другую категорию/подборку. Если подборки ещё нет — можно создать её прямо в модальном окне на лету! Товар вставляется **ровно в середину** подборки, не нарушая топ витрины.
   - **Умное мультивыделение:**
     - Когда ни одна карточка не выбрана — клики по карточкам открывают ссылки / перетаскивают, случайных выделений нет.
     - Как только менеджер ставит галочку хотя бы на одной карточке — включается режим выделения: теперь можно кликать по **любой части карточки**, и она сразу выделяется/снимается.

2. **⚡ Фильтры подборки:**
   - Кнопка `⚡ Фильтры` в верхней панели:
     - Просмотр всех фильтров подборки и количества товаров в каждом.
     - Создание нового фильтра (`+ Новый фильтр`) с автоматической генерацией слага и указанием ключевых слов.
     - Смена порядка фильтров кнопками `⬆️` и `⬇️` (влияет на порядок кнопок-чипсов на сайте).
     - Редактирование названий (`label`) и ключевых слов (`keywords`).
     - Удаление ненужных фильтров.

3. **🗑️ Корзина и модерация:**
   - Вкладка «Корзина» содержит товары, удалённые из подборки.
   - Причины удаления и бейджи: спам, дубликат, низкое качество, заметки.
   - Товары из корзины можно:
     - **Вернуть (`↩️`)** обратно в текущую подборку.
     - **Восстановить в другую подборку (`↪️ В другую`)** — вставляет товар в середину выбранной подборки или создаёт новую подборку на лету с предложением сразу перейти туда.
     - **Удалить навсегда (`❌`)** в `delete_links.txt`.

4. **📁 Управление категориями и подборками:**
   - Кнопка `📁 Структура витрины`:
     - Создание новых категорий и подборок.
     - Изменение порядка подборок и разделов.
     - Редактирование описаний, заголовков и обложек.

## 3. Парсинг и сбор товаров
- **Скрипт синхронизации:** `npm run sync` (полный интерактивный парсер).
- **⚡ Быстрый сбор витрины (Черновики за 1-2 минуты):** `npm run showcase:quick <категория> <подборка>`
  - Мгновенно собирает картинки, заголовки и ссылки со страниц поисковой выдачи Creative Fabrica.
  - Сразу выставляет все товары на витрину в админку с бейджем `⚡ Черновик`.
  - Менеджер не ждёт часами: открывает админку `http://localhost:3333`, удаляет ненужные товары, оставляет только нужные клипарты.
- **🎯 Допарсинг одобренных товаров (Deep Parse):** `npm run drafts:hydrate <категория> <подборка>` (или кнопка `🎯 Допарсить` в админке).
  - Скачивает full HD галереи всех ракурсов, полные описания, отзывы и теги ТОЛЬКО для оставшихся после чистки товаров.
  - Превращает их в полноценные чистовые карточки (`isDraft: false`).
- Товары сохраняют метаданные источника:
  - `sourceQuery` — поисковый запрос, по которому товар был найден.
  - `sourceComment` — комментарий менеджера к задаче парсинга.
- Эти данные отображаются в карточке товара в админке с иконками 🔍 и 💡 для удобного контроля качества.

## 4. Браузерное расширение (Creative Fabrica Clipper)
Для точечного и быстрого сбора товаров прямо во время сёрфинга по сайту `creativefabrica.com` создано официальное браузерное расширение **Artify Studio Clipper** (папка `extension/`, архив `artify-extension.zip`).

### Установка (Chrome, Brave, Edge, Яндекс):
1. Открыть `chrome://extensions` в браузере.
2. Включить «Режим разработчика» в правом верхнем углу.
3. Нажать «Загрузить распакованное расширение» и указать папку `extension/` проекта.
4. Закрепить иконку 🎨 на панели браузера.

### Возможности расширения:
- **Подсветка карточек на Creative Fabrica:**
  - `➕ В коллекцию` / `⚡ В черновик` — товар еще не добавлен. Нажатие добавляет товар в выбранную подборку за 1 секунду.
  - `✅ На сайте` / `⚡ Черновик` — товар уже есть в текущей подборке Artify Studio (защита от дублей).
  - `🗑 В корзине` — товар ранее был забракован менеджером в корзину (защита от повторного сбора).
- **Пакетное добавление (Чекбоксы):**
  - На каждой карточке есть галочка. Можно отметить 10-20 понравившихся товаров и в плавающем виджете снизу нажать `⚡ Добавить выбранные (N)`.
- **Глубокий парсинг со страницы товара (`/product/*`):**
  - Прямо под кнопкой покупки внедряется блок Artify Studio.
  - Две кнопки: `⚡ Черновик (1 сек)` (мгновенно с HD-превью) и `🎯 Полный парсинг` (собирает всю галерею фото, описание, теги дизайнера, рейтинг и отзывы через открытую сессию браузера менеджера).

## 5. Правило разделения ролей (Менеджер / Разработчик)
- **Менеджер и ИИ-помощник менеджера:**
  - Работает с товарами, подборками, фильтрами, описаниями и корзиной через веб-интерфейс http://localhost:3333 и браузерное расширение.
  - **Разрешённые команды терминала:**
    - Запуск/перезапуск админки: `npm run admin`
    - Запуск локального сайта витрины: `npm run dev` (http://localhost:4321)
    - Подтягивание свежих обновлений от разработчика: `git pull origin main`
    - Проверка статуса: `git status`
    - Упаковка расширения: `npm run pack:extension`
  - ⛔ **СТРОГО ЗАПРЕЩЕНО:**
    - Делать `git push` в удаленный репозиторий (защита от затирания кода).
    - Вручную редактировать программные файлы кода (`src/`, `scripts/`, `package.json`).
  - При возникновении технических ошибок или необходимости доработки функций — ИИ формирует ТЗ для разработчика, менеджер передаёт его владельцу.
- **Разработчик (Владелец):**
  - Вносит изменения в JavaScript/Astro код (`scripts/`, `src/`).
  - Тестирует и пушит код в репозиторий (`git push origin main`).
  - Разворачивает сайт на Cloudflare Pages (`npm run build`).
