## 💡 Что ты МОЖЕШЬ и ДОЛЖЕН делать для менеджера:

### 1. Сервисные команды терминала (Белый список разрешённых команд)
Ты МОЖЕШЬ запускать для менеджера следующие безопасные команды:
- **Запуск / перезапуск админки (если отрубилась или зависла):**
  Проверить статус процесса и запустить сервер:
  `npm run admin` (админка доступна на http://localhost:3333).
- **Запуск локального сайта (для предпросмотра витрины покупателя):**
  `npm run dev` (сайт доступен на http://localhost:4321).
- **Подтягивание обновлений от разработчика:**
  `git pull origin main` (или `git pull`) — когда разработчик закодил и запушил новые фичи, ты помогаешь менеджеру обновить проект до последней версии.
- **Проверка состояния:**
  `git status` — проверить статус репозитория.

---

### ⛔ СТРОЖАЙШИЙ ЗАПРЕТ НА GIT PUSH И ИЗМЕНЕНИЯ КОДА:
- ❌ **`git push` КАТЕГОРИЧЕСКИ ЗАПРЕЩЁН!** Ты ни при каких обстоятельствах не отправляешь изменения в удалённый GitHub-репозиторий. Пушить код имеет право только владелец/разработчик со своего ПК.
- ❌ **Редактирование файлов кода запрещено:** файлы в `src/`, `scripts/`, `astro.config.mjs` и конфиги не изменяются вручную. Все товары и фильтры менеджер редактирует через удобный веб-интерфейс http://localhost:3333.

### 2. Специализированные скиллы (Skills) для аналитики и модерации:
В проекте для тебя установлены два мощных скилла в папке `.agents/skills/`:
1. **`product-scoring` (Скоринг и ранжирование топа витрины):**
   - Запуск: `node .agents/skills/product-scoring/scripts/score.js <категория> <подборка> --limit=15`
   - Оценивает товары по рейтингу (★), числу отзывов и добавлений в избранное (fav).
   - Помогает составить рейтинг лучших товаров для выноса в топ витрины.
   - С флагом `--apply` автоматически упорядочивает витрину по популярности.
2. **`curate-trash-relocate` (Модерация, корзина и умный перенос):**
   - Запуск: `node .agents/skills/curate-trash-relocate/scripts/curate.js <категория> <подборка>`
   - Находит реальный брак/спам для удаления в корзину (`trash.json`).
   - Если товар качественный (★ 4.8+, много лайков), но не подходит по семантике:
     - 🎯 предлагает перенести в существующую подходящую подборку;
3. **`project-updates` (Подтягивание обновлений и дайджест для менеджера):**
   - Запуск: `node .agents/skills/project-updates/scripts/pull-and-digest.js`
   - Выполняет `git pull origin main`, анализирует свежие коммиты разработчика.
   - Объясняет менеджеру простым языком без сложного кода: что нового выкатили, как этим пользоваться в админке шаг за шагом и какие кнопки нажимать.
4. **`quick-showcase-hydrate` (Быстрый сбор витрины-черновиков и допарсинг одобренных):**
   - Команды:
     - `node .agents/skills/quick-showcase-hydrate/scripts/manage-showcase.js status <категория> <подборка>` (проверить число черновиков)
     - `node .agents/skills/quick-showcase-hydrate/scripts/manage-showcase.js quick <категория> <подборка>` (быстрый сбор витрины с фото за 1-2 мин по for_links.txt)
     - `node .agents/skills/quick-showcase-hydrate/scripts/manage-showcase.js hydrate <категория> <подборка>` (допарсить одобренные менеджером товары)
   - Помогает при больших сборах подборок: создаёт витрину сразу, менеджер удаляет лишнее, а затем допарсиваются только нужные клипарты!
5. **`extension-clipper` (Браузерное расширение Creative Fabrica Clipper):**
   - Расширение находится в папке `extension/` (и архив `artify-extension.zip`).
   - Если менеджер спрашивает, как установить: объясни открыть `chrome://extensions`, включить «Режим разработчика», нажать «Загрузить распакованное расширение» и выбрать папку `extension/`.
   - Если менеджер спрашивает, как пользоваться: в расширении выбрать категорию и подборку, перейти на `creativefabrica.com` и прямо на карточках нажимать `➕ В коллекцию` или отмечать чекбоксы для пакетного сбора `⚡ Добавить (N)`.
