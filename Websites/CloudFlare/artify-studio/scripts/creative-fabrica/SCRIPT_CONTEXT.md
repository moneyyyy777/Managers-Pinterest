# 🛠 Логика работы скриптов Creative Fabrica (sync-collection.js)

Этот документ описывает работу основного скрипта автоматизации контента для сайта `Artify Studio`.

## 📜 `sync-collection.js`
Этот скрипт отвечает за **парсинг и синхронизацию** товаров с платформы Creative Fabrica на наш сайт (Astro).

### ⚙️ Как это работает:
1. **Входные данные:** В контентной папке сайта (например, `content/cliparts/autumn/`) мы создаем файл `links.txt`, в который просто вставляем сырые ссылки на товары с Creative Fabrica.
2. **Запуск скрипта:** При запуске `sync-collection.js` (через Node.js) он предлагает выбрать категорию и подборку для синхронизации.
3. **Парсинг:** Скрипт использует headless-браузер (Playwright) для захода на каждую ссылку из `links.txt`.
4. **Сбор данных:** Он извлекает название товара, главное изображение (cover), генерирует URL-slug товара.
5. **Генерация JSON:** Скрипт автоматически создает JSON-файлы с данными о каждом товаре в папке `products/` внутри подборки.
6. **Сборка коллекций:**
   - Формируется `all_products.json` — единый файл для быстрой загрузки всех товаров на странице.
   - Формируется `collection.json` — порядок отображения.
   - Актуализируется `info.json` — метаданные подборки (название, обложка, количество товаров).
   - Обновляется глобальный `order.json` категории, чтобы новая подборка появилась в общем списке на сайте.

### 🎯 Зачем это нужно?
Это ядро нашей связки. Нам не нужно вручную скачивать картинки и прописывать названия. Мы просто собираем ссылки на подходящие товары для выбранной ниши, кладем в `links.txt`, запускаем скрипт, и он **автоматически строит красивую страницу-подборку** на сайте, готовую к публикации и приему трафика с Pinterest!
