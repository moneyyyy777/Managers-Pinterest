# 🧠 Контекст: Artify Publishing Orchestrator

**Путь:** `Websites/CloudFlare/artify-studio/scripts/artify_sites_publishing/`

Это сердце технической автоматизации проекта — мощный модульный комбайн (State Machine), который без участия человека выстраивает всю трафиковую воронку (PBN-сеть) для Pinterest.

## 🎯 Что делает этот скрипт?
Он берет путь к готовой папке с тегами из `tasks.txt` (например, `Keywords/Artify Studio/Cliparts/Watercolor`) и по цепочке превращает её в готовую боевую единицу для отдела автоматизации.

Скрипт полностью идемпотентен: если он упадет на середине (например, отвалится интернет), при повторном запуске он продолжит работу ровно с того места, где остановился, опираясь на базу `cloudflare_accounts.json`.

## 🧩 Модули Оркестратора

### 1. `1_html_builder.js` (Модуль Cloudflare)
Генерирует HTML-страницу с фейковой капчей и автоматически деплоит её на бесплатный хостинг Cloudflare Pages через консоль `wrangler`. Умеет обходить коллизии имен сабдоменов (добавляя суффиксы `artifystudio333` и т.д.).

### 2. `2_analytics.js` (Модуль GA4)
Обращается к Google Analytics Admin API. Создает новый поток данных, получает уникальный код `G-XXXXXXXX` и записывает его в базу `analytics_g_rules.json`. Позволяет нам отслеживать каждый клик с Pinterest.

### 3. `3_google_sites.js` + `3_1_resizeEmbedBlock.js` (Модуль Робота)
Скрипт на базе **Playwright**, который открывает настоящий браузер Chrome через CDP (порт 9222) и имитирует действия человека:
1. Клонирует базовый шаблон Google Sites.
2. Встраивает наш HTML с Cloudflare через Iframe.
3. *Движок Burst Resize:* Уникальный алгоритм, который физически "тянет" Iframe вниз до высоты 1800-1950px короткими рывками, обходя ограничения Google.
4. Устанавливает Favicon (ищет файл `logo.png` в папках менеджера).
5. Расшаривает доступ на 10 других наших Gmail-аккаунтов (для безопасности).
6. Публикует сайт со слагом и вставляет код аналитики.

### 4. `4_database.js` (Модуль Балансировщика)
Следит за лимитами аккаунтов. Как только на одном Cloudflare аккаунте набирается 150 сайтов, он автоматически переключает деплой на следующий аккаунт из списка.

### 5. `5_file_manager.js` (Модуль Упаковки)
Финальный этап. Скрипт забирает пронумерованные папки (с тегами, Excel-шаблонами) из творческой мастерской, вписывает в них свежесозданную ссылку на Google Site (`Link_Site.txt`), переименовывает под стандарты автоматизации (добавляет дату, суффиксы WL) и складывает всё это в финальную папку `ALL FOLDERS`.

## 🚀 Резюме
Оркестратор — это конвейер. Менеджер собирает теги, генерирует Excel-файлы и кидает путь в `tasks.txt`. Скрипт делает всё остальное: собирает сайты, настраивает аналитику и упаковывает готовые папки, которые сразу отправляются на заливку 3000 пинов.
