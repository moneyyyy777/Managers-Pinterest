---

# 1. Важное уточнение после обсуждения Christmas Bundles

В предыдущем аудите я слишком жёстко трактовал слово **bundle** как просто формат товара.

Это было неправильно.

Если на Creative Fabrica действительно существует отдельный пул товаров, которые являются **готовыми Christmas Bundles**, и пользователь Pinterest ищет именно такие готовые наборы, то:

```text
/christmas-bundles
```

может быть **полноценной правильной коллекцией**.

Почему?

Потому что `Bundle` в данном случае — не случайный технический формат внутри страницы, а **реальное покупательское намерение**:

> «Мне нужен готовый набор Christmas design resources».

При этом внутри bundles могут находиться разные asset types:

- SVG
- PNG
- fonts
- sublimation
- clipart
- templates
- paper
- элементы для Cricut и т.д.

Это не обязательно ломает коллекцию, если человек покупает их **как единый Christmas bundle**.

---

# 2. Поэтому правило Artify Studio нужно сформулировать точнее

Старая формула:

```text
PRODUCT TYPE + BUYER INTEREST + AESTHETIC
```

хорошая, но недостаточно гибкая.

Используем теперь:

```text
COLLECTION = ЕДИНЫЙ SEARCH / BUYER INTENT
```

А уже внутри него проверяем:

1. Один ли основной покупатель?
2. Один ли основной сценарий использования?
3. Один ли поисковый intent?
4. Можно ли показать товары вместе без ощущения «что это вообще за страница?»
5. Есть ли достаточный объём товаров?
6. Можно ли сформировать отдельную Pinterest-аудиторию?

Если **да** — коллекция может существовать даже тогда, когда внутри неё несколько типов файлов.

---

# 3. Когда MIXED PRODUCT TYPES допустим

### Можно

```text
/christmas-bundles
```

если товары действительно являются Christmas bundles.

Покупатель не думает:

> «Я пришёл за PNG».

Он думает:

> «Мне нужен Christmas design bundle».

---

### Нельзя

```text
/wedding-svg-fonts
```

Потому что это два самостоятельных поисковых намерения:

- wedding SVG
- wedding fonts

Человек, ищущий font, не обязательно хочет SVG.

Лучше:

```text
/svg/wedding
/fonts/wedding
```

---

### Можно рассмотреть

```text
/baby-shower-bundles
```

если на CF есть достаточное количество именно готовых Baby Shower bundles.

То есть здесь работает не принцип:

> «одна страница = один extension файла».

Работает принцип:

> **«одна страница = одно сильное покупательское намерение».**

# 6. Самое важное изменение: как теперь оценивать новую нишу

Перед созданием URL Artify Studio задаёт 6 вопросов.

### 1. Что именно человек ищет?

Не просто:

> Christmas

А:

> Christmas bundle

или:

> Christmas tumbler wrap

или:

> Retro Christmas clipart.

---

### 2. Есть ли реальный товарный пул?

Если на Creative Fabrica есть 20–100+ релевантных товаров — коллекция потенциально жизнеспособна.

Если есть 3 случайных товара — не стоит строить под них отдельную страницу.

---

### 3. Совпадает ли Pinterest-аудитория?

Например:

```text
Christmas Bundle
```

может иметь одну Pinterest-аудиторию.

А:

```text
Wedding Font
Wedding SVG
Wedding Mockup
```

могут пересекаться, но имеют разные product-search intents.

---

### 4. Может ли человек сразу понять страницу?

Хорошая коллекция:

```text
Christmas Bundles
```

Человек сразу понимает:

> «Здесь готовые Christmas bundles».

Плохая:

```text
Design Resources
```

Слишком широко.

---

### 5. Есть ли место для aesthetic variations?

Например:

```text
Christmas Bundles
├── Retro
├── Coquette
├── Vintage
├── Funny
├── Rustic
└── Cute
```

Это идеальная ситуация.

Один intent → несколько tastes.

---

### 6. Можно ли построить отдельный Pinterest content engine?

Если под коллекцию можно сделать:

- 20–50+ pin concepts
- разные keywords
- разные visual treatments
- разные boards
- разные long-tail queries

то коллекция особенно привлекательна.

---

# 7. Финальная модель Artify Studio

Теперь архитектура выглядит так:

```text
SECTION
│
├── PRODUCT / FORMAT INTENT
│
├── BUYER / USE CASE
│
└── AESTHETIC VARIATIONS
```

Но **не обязательно каждый уровень должен физически становиться URL**.

URL появляется только тогда, когда у него есть самостоятельный search intent и достаточный ассортимент.

# 9. ФИНАЛЬНЫЙ ПРИНЦИП

Не использовать правило:

> «Один extension = одна коллекция».

И не использовать правило:

> «Одна тема = одна коллекция».

Использовать:

> **Одна коллекция = один достаточно сильный поисковый и покупательский intent.**

А внутри этого intent можно спокойно объединять несколько типов файлов, **если именно это и является товарным предложением**, например:

```text
Christmas Bundle
= SVG + PNG + Fonts + Clipart + Sublimation
```

Потому что пользователь покупает не конкретное расширение.

Он покупает:

> **готовый Christmas Bundle.**

Это и есть правильная логика для Artify Studio.
