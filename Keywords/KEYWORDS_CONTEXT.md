# 🧠 Контекст папки: Keywords (Творческая мастерская и Семантика)

Эта папка является "мозговым центром" проекта. Здесь происходит вся аналитическая и творческая работа по подбору семантики (тегов) и подготовке структуры ниш перед тем, как они отправятся на массовую автоматизацию.

## 📁 Структура
Папки внутри разделены по проектам (например, `Artify Studio`), затем по крупным темам (`Cliparts`, `Christmas`, `Fonts`), а внутри них — по узким целевым аудиториям (поднишам).
*Пример глубокой сегментации:* `Artify Studio / Cliparts / Baby` делится на `Nursery Baby Clipart` (декор детской), `Baby Clipart Shower` (праздник) и т.д. Это позволяет бить точно в цель, не смешивая аудитории.

**Особая папка `ALL FOLDERS` (внутри проектов):**
Здесь находится финальная станция творческой мастерской. В этой папке лежат итоговые, полностью очищенные и переименованные папки-шаблоны (результат работы скриптов подготовки). Это готовые пакеты, которые "под ключ" отправляются в отдел регистрации и автоматизации, чтобы они могли брать каждую папку в работу и заливать контент.

## 🔄 Жизненный цикл файлов семантики (Воронка тегов)
Внутри папки каждой ниши генерируется стандартный набор текстовых файлов, по которым теги проходят от сырых "семян" до готовых кластеров:

1. **`Seed Tags.txt`** — Сюда кладутся стартовые "семена" (узкие и широкие ключевые слова), сгенерированные ИИ. Они загружаются в парсер Pininspector.
2. **`Pininspector.txt`** — Сюда сохраняются сырые теги после успешного парсинга выдачи Pininspector.
3. **`Pininspector + Seeds.txt`** — Объединенный список (семена + спарсенные теги). Именно этот файл подхватывается автоматическим скриптом парсинга объемов (`searchvolume.js`).
4. **`[Имя_папки] (All).csv`** — Результат работы `searchvolume.js`. Файл со всеми тегами и их частотностью (объемом поиска).
5. **`[Имя_папки] (Filter by OpenAI).csv`** — Чистовик. Сюда кладутся теги из `(All).csv`, отфильтрованные через наш ИИ-промпт (удалены бренды конкурентов, нерелевантные теги и мусор).
6. **`[Имя_папки] (Itent ...).txt`** (Опционально) — Если тегов много, чистые теги из `(Filter by OpenAI).csv` дополнительно разбиваются на интенты (смысловые группы) в отдельные файлы, чтобы на одну доску лился трафик одного намерения (повышает CTR).

*Примечание для AI:* Все рабочие промпты для генерации ниш, фильтрации тегов и создания скриптов лежат в корне проекта в файле `PROMPT_TEMPLATES.md`.

## 🚀 Ускорители
Внутри находится папка `Scripts for Faster` — набор скриптов, которые автоматизируют создание этих самых файлов семантики, парсинг частотности, перенос папок в `All Folders` и массовую генерацию продающих текстов для пинов. Подробнее читай в `SCRIPTS_FOR_FASTER_CONTEXT.md`.
