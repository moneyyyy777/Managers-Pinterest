  Cliparts/Baby/                       ← КОРЕНЬ НИШИ (здесь linksite.txt, all_products.json)
  ├── Baby Cliparts Shower/            ← ПОДНИША (аудиторный сегмент)
  │   ├── 1 ... Filter by OpenAI/     ← ОБЩИЙ файл (все теги подниши смешаны)
  │   │   └── For Main/

  │   │   └── For Main/

Что читать:

ШАГ 1.5: ОБУЧЕНИЕ И ПОЛНЫЙ КОНТЕКСТ
════════════════════════════════════════
ПЕРЕД генерацией тебе нужно понять ВСЕЙ НИШЕ ЦЕЛИКОМ, а не только текущую папку.

▸ ПОЛНАЯ КАРТА НИШИ:
  Прочитай теги (Boards_Tags.txt) из ВСЕХ подниш и стратегий в этой нише.
  Ты должен понимать: какие аудитории охвачены, какие темы, какие интенты.
  Это нужно, чтобы правильно расставить стоп-слова и выбрать глубину текста.
  Ты должен мыслить как человек, который СПРОЕКТИРОВАЛ эту файловую структуру —
  он разделил аудиторию на сегменты осознанно, и ты должен понять его логику.

▸ ОБУЧЕНИЕ ПО ЭТАЛОНУ:
  Если в какой-то папке уже есть заполненный Excel (столбцы L, M, N — Description,
  CTA, Title, начиная со строки 2) — прочитай 20-30 строк как ОБРАЗЕЦ:
  - Какой стиль текста? Насколько конкретно/абстрактно?
  - Как упоминается товар? Какие формулировки?
  - Как используются эмодзи?
  Это твой ориентир по стилю. Генерируй в том же духе.
  Если заполненных Excel нет — генерируй по правилам ниже, используя свой ум.

ШАГ 2: ПЛАНИРОВАНИЕ — ДЛЯ КАЖДОЙ СТРАТЕГИИ ОПРЕДЕЛИ НАСТРОЙКИ
════════════════════════════════════════
Для каждой папки-стратегии ты АВТОМАТИЧЕСКИ определяешь:

▸ ТИП ФАЙЛА: «общий» (Filter by OpenAI) или «интент» (Itent ...)
  - Общий = теги разнородные, тексты должны быть АБСТРАКТНЫМИ (золотая середина)
  - Интент = теги однородные, тексты могут быть ЧУТЬ конкретнее

▸ НИША: Прочитай ВСЕ теги из Boards_Tags.txt и определи два слоя:
  - ТИП ПРОДУКТА (watercolor, svg, font, clipart...) — ТОЛЬКО если слово есть в тегах
  - ТЕМА / СЮЖЕТ (baby, food, christmas...) — что объединяет ВСЕ теги
  Ниша = ТЕМА + ТИП ПРОДУКТА (если он есть в тегах). Не додумывай.

▸ СТОП-СЛОВА: Посмотри на СОСЕДНИЕ ПОДНИШИ (аудиторные сегменты) одного уровня.
  Их ключевые слова = стоп-слова для текущей папки.

  ⚠️ ВАЖНО: Стоп-слова берутся ТОЛЬКО из ПОДНИШ, а НЕ из интентов!
  Интенты внутри одной подниши (Filter by OpenAI, Itent CLIPART, Itent INVITATIONS, 
  Itent DIY) — это ЧАСТИ ОДНОГО ЦЕЛОГО. Они не конкурируют друг с другом.
  Например: «Invitations» НЕ является стоп-словом для интента «CLIPART» 
  в поднише Baby Shower — потому что invitations это ЧАСТЬ baby shower темы.

  Стоп-слова = названия ДРУГИХ подниш на уровне выше.
  Пример: если работаешь внутри «Baby Cliparts Shower», а рядом есть 
  «Baby Cliparts Nursery» — слово «nursery» запрещено.

  Под капотом: Каждая подниша продвигается ОТДЕЛЬНО, на свой трафик.
  Если ты заполняешь «Baby Cliparts Shower», а рядом есть «Baby Cliparts Nursery» —
  слово «nursery» ЗАПРЕЩЕНО в твоих текстах. Иначе мы перетянем трафик
  с одной подниши на другую, а нам нужна уникальность каждой доски.
  
  Логика: если человек ищет baby shower и видит текст «perfect for nursery decor» —
  он уйдёт, потому что это не то, что он искал. А человек, который ищет nursery,
  получит наш пин через ДРУГУЮ доску с правильными текстами.

▸ ПОДСКАЗКА НИШИ (niche_hint): Если теги неоднозначны (могут трактоваться
  по-разному), выбери направление, которое лучше всего описывает БОЛЬШИНСТВО тегов.

1️⃣ 100 ЗАГОЛОВКОВ (TITLES):
   - Без эмодзи, без знаков препинания в конце
   - 3-8 слов
   - Содержат ключевые слова из тегов, но ЕСТЕСТВЕННО вписанные
   - НЕ привязаны к одной конкретной картинке

2️⃣ 100 ОПИСАНИЙ (DESCS):
   - ⚠️ КАЖДАЯ строка ОБЯЗАТЕЛЬНО начинается с эмодзи по смыслу
   - Без артикля "A" в начале
   - Без призыва к действию (это задача CTA)
   - 1-2 предложения
   - Должны подходить к ЛЮБОЙ картинке из выдачи по тегам

3️⃣ 100 ПРИЗЫВОВ К ДЕЙСТВИЮ (CTA):
   - ⚠️ КАЖДАЯ строка ОБЯЗАТЕЛЬНО начинается с эмодзи
   - Одно короткое предложение
   - Призыв перейти и скачать товар
   - В 70% CTA используй слово FREE (БОЛЬШИМИ БУКВАМИ, с акцентом)
   - Название типа товара с Заглавной (например: Clipart, Fonts, SVG)
   - НЕ упоминай названия конкретного ПО (Canva, Adobe) — пиши про сам товар
   - Разные формулировки, не повторяться

ЗОЛОТОЕ ПРАВИЛО ТЕКСТОВ:
Представь, что ты берёшь РАНДОМНЫЙ заголовок + РАНДОМНОЕ описание + РАНДОМНЫЙ CTA.
Они должны идеально сочетаться и подходить к ЛЮБОЙ картинке из выдачи по тегам.

Для ОБЩЕГО файла (Filter by OpenAI): пиши ШИРЕ. Теги разнородные,
поэтому тексты должны работать для всех тегов одновременно.
Используй слова уровня ниши, не уходи в под-тему.

Для ИНТЕНТ-файла: можно ЧУТЬ конкретнее, но всё равно не привязывайся
к одному объекту. Теги внутри интента однородны, но картинки всё равно разные.

ПРАВИЛО ВИЗУАЛЬНОГО СТИЛЯ
════════════════════════════════════════
Слова типа «watercolor», «boho», «floral», «vintage», «minimalist», «vector» 
описывают ВИЗУАЛЬНЫЙ СТИЛЬ — то, КАК выглядит картинка.

⚠️ Используй стиль в текстах ТОЛЬКО если он есть в ПОДАВЛЯЮЩЕМ БОЛЬШИНСТВЕ тегов.
Если теги общие (например «baby shower clipart», «baby shower png»), 
то скрапленная картинка может быть в ЛЮБОМ стиле — watercolor, boho, 
flat vector, 3D, line art. А ты написал «Watercolor» в заголовке — 
и теперь текст не подходит к 80% картинок.

Под капотом: Представь — скрапер берёт картинку по тегу «baby shower clipart».
На ней — boho-стиль с перьями. А под ней заголовок «Watercolor Baby Shower Art».
Человек видит несоответствие → не кликает → CTR падает.

Поэтому: если стиль НЕ указан явно в КАЖДОМ теге доски — не используй его в текстах.
Пиши нейтрально: «digital clipart», «beautiful graphics», «stunning designs».

ПРИНЦИП МАКСИМАЛЬНОЙ ГЛУБИНЫ (САМОЕ ВАЖНОЕ)
════════════════════════════════════════
Погружайся в тематику настолько ГЛУБОКО, насколько позволяет набор тегов.
НО — останавливайся ровно в той точке, где ЛЮБОЙ случайный пин из ЛЮБОГО тега 
этой доски всё ещё на 100% подходит под твой текст.

Под капотом: Не пиши слишком общо — «Beautiful digital art for your projects» 
скучно и не конвертирует. Но и не пиши слишком узко — «Adorable pink elephant 
with balloons» подойдёт только к одной картинке из сотни.

Алгоритм мышления:
1. Прочитай ВСЕ теги доски
2. Представь самую ШИРОКУЮ картинку, которая может выпасть (минимум деталей)
3. Представь самую УЗКУЮ картинку (максимум деталей)
4. Твой текст должен одинаково хорошо подходить к ОБЕИМ
5. Если подходит — ты нашёл правильную глубину. Зафиксируй этот уровень.

ШАГ 4: САМОВЕРИФИКАЦИЯ
════════════════════════════════════════
ПЕРЕД выводом результата проверь каждый блок:

✅ ФОРМАТ:
   - Ровно 100 строк в каждом блоке?
   - Эмодзи в начале КАЖДОЙ строки desc и CTA?
   - Нет нумерации, пустых строк?

✅ УНИКАЛЬНОСТЬ (САМАЯ ВАЖНАЯ ПРОВЕРКА):
   - Убери эмодзи из начала строк и сравни тексты — сколько ПОЛНОСТЬЮ одинаковых?
   - Если уникальных строк менее 85 из 100 — ПЕРЕДЕЛАЙ блок
   - Недопустимо: одна фраза повторена 5+ раз с разными эмодзи

✅ СТОП-СЛОВА:
   - Ни одно слово из списка соседних подниш не просочилось?
   - Поиск: пройди каждый стоп-слово по всем 300 строкам

✅ MATCH-TO-MATCH:
   - Возьми рандомный title[17] + desc[42] + cta[88] — звучит ли естественно?
   - Повтори 3 раза с разными номерами

✅ ЗОЛОТАЯ СЕРЕДИНА:
   - Не слишком конкретно? (нет привязки к одному объекту на картинке)
   - Не слишком абстрактно? (человек понимает, что ему предлагают)

Если хоть одна проверка FAIL — переделай конкретный блок, не выводи мусор.

ШАГ 5: ВЫВОД РЕЗУЛЬТАТА
════════════════════════════════════════
❌ НЕ перезаписывай Excel-файлы.
✅ Выведи результат в чат в формате Markdown-таблицы (столбцы: № | Title | Description | CTA).
Архитектор/Контроллер сам проверит твои тексты и запишет их НАПРЯМУЮ в файлы `.xlsx` с помощью скрипта.

Для КАЖДОЙ обработанной стратегии выведи:

📋 ОТЧЁТ:
- Путь к папке
- Определённая ниша
- Стоп-слова (и откуда взяты)
- Тип файла (общий/интент)

Затем саму Markdown-таблицу на 100 строк.

Если обрабатываешь несколько стратегий — выводи последовательно, по одной.
