# ⚡ Контекст папки: Scripts for Faster (Скрипты Ускорения)

Здесь собраны скрипты и автоматизации, которые избавляют менеджера от рутинной работы: от создания базовых текстовых файлов до массового сбора статистики и сборки готовых папок-шаблонов для регистрационного отдела.

## 🌟 Главное Ноу-Хау: `ai_auto_content_filler_UI.py`
Мощный инструмент с графическим интерфейсом (Streamlit), который полностью автоматизирует процесс генерации продающих текстов для пинов.
* **Логика:** Через headless-браузер (Playwright) заходит в Google AI Studio, скармливает промпт и JSON товара. Строго контролирует ИИ (требует ровно 100 строк заголовков, описаний и CTA).
* **Маркетинг:** Заставляет ИИ ставить эмодзи, писать "FREE" в 70% CTA и избегать названий чужих брендов ПО.
* **Результат:** Сам вписывает идеальный контент в столбцы 12, 13, 14 файла Excel.

## 🛠 Скрипты конвейерной подготовки ниши (Pipelines)

Эти скрипты используются последовательно, чтобы с нуля создать готовую нишу и прогнать её по воронке тегов.

### 1. `first_creator_files.py`
* **Логика работы:** Моментально создает пустую "базу" файлов в текущей папке: `Seed Tags.txt`, `Pininspector.txt`, `Pininspector + Seeds.txt`, `(All).csv`, `(Filter by OpenAI).csv`.
* **Для чего нужен:** Создает плацдарм для воронки семантики. Сюда мы будем складывать семена, парсить теги, прогонять их через поиск объемов и фильтровать через OpenAI, не создавая файлы вручную.

### 2. `searchvolume.js`
* **Логика работы:** Это Node.js скрипт на базе Playwright. Он ищет файлы `Pininspector + Seeds.txt` (в которых лежат семена + спарсенные теги), заходит на сайт **searchvolume.io** пачками по 600 штук, решает капчу (Buster) и обходит лимиты по IP (ротация стран через Qu VPN).
* **Для чего нужен:** Автоматический, бесплатный сбор Search Volume (объема поиска) для базы тегов. Результат аккуратно сохраняется в `(All).csv` с сортировкой по частотности, который дальше пойдет на фильтрацию OpenAI.

### 3. `second_creator_itenttag.py`
* **Логика работы:** В цикле просит ввести название "Интента" и создает текстовые файлы `(Itent ...).txt`.
* **Для чего нужен:** Когда ИИ (ChatGPT/Gemini) разбивает отфильтрованные в чистовике `(Filter by OpenAI).csv` теги на смысловые кластеры, скрипт позволяет за секунды создать текстовики для копипаста каждого кластера.

### 4. `third_copier_folders.py`
* **Логика работы:** Мост между `Keywords` и `All Folders`. Находит файлы с интентами и чистовики тегов. Затем просит выбрать шаблон из `All Folders`, копирует туда всё содержимое `Template`, переименовывает `.xlsx` файлы и автоматически заполняет `For Main/Boards_Tags.txt` и `Boards_Name.txt` чистыми тегами.
* **Для чего нужен:** Всю собранную семантику он сам превращает в готовые сборочные цеха для регистрационного отдела. Никакого ручного копирования.

### 5. `final_namer_folder.py`
* **Логика работы:** Массово переименовывает готовые папки, добавляя к ним суффиксы платформы (Netlify, Cloudflare), статусы (WL, LU) и текущую дату. Просит ввести финальную ссылку-прокладку (пишет её в `Link_Site.txt`) и генерирует текстовые списки с полными Windows-путями к папкам.
* **Для чего нужен:** Финальная маркировка папок перед отправкой на Windows-серверы автоматизации (Make), чтобы скрипты подхватили их и знали целевые ссылки для трафика.
